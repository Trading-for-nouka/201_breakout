# 🚀 201_breakout — ブレイクアウト戦略

7日高値ブレイク・出来高急増・RSフィルター（3〜7%）で銘柄をスキャンし、
エントリー後は毎日モニタリングして決済シグナルを Discord に通知します。

## 戦略概要（バックテスト 2016–2025）

| 項目 | 値 | 備考 |
|---|---|---|
| 勝率 | **55.1%** | monitor.py出口ルール適用後 |
| プロフィットファクター | **1.41** | 同上・全シグナル |
| 平均損益 | +0.50% | 同上 |
| 取引数 | 17,434件 | 同上 |
| 平均保有日数 | 21日（上限） | |
| 損切り | -5% または ATR×1.5 | 先に発動した方 |

> **スコアリング改善（2026-05-24更新）**
> バックテスト分析によりRVOLスコアを3段階化し、スコア閾値50点未満を除外。
> 低PF帯（旧35点・旧50点RVOL<1.5）を自動排除し成績を安定化。

> **RS上限フィルター（2026-05-10追加）**
> RS > 7% の過熱銘柄を除外。

## エントリー条件（全条件AND）

| 条件 | 基準値 | 内容 |
|---|---|---|
| トレンド確認 | MA20 > MA50 | 短期MA > 長期MA |
| ブレイクアウト | 終値 > 前日7日高値 | 7日間の高値を終値が上抜け |
| 相対強度（下限） | RS ≥ +3.0% | TOPIXより3%以上アウトパフォーム |
| 相対強度（上限） | RS < +7.0% | 過熱防止 |
| 52週高値圏 | 終値 ≥ 52週高値×90% | 高値から10%以内 |
| 売買代金 | TOPIX区分別 | Core30=無制限 / Large70=5億円 / Mid400=1億円 |
| 決算除外 | 5日以内 | 決算発表日が5日以内の銘柄を除外 |
| **スコア閾値** | **≥ 50点** | **スコアリング後に低スコア銘柄を除外** |

## スコアリング

フィルター通過後にスコアを計算し、**50点未満は除外**します。

| 項目 | 条件 | 加点 |
|---|---|---|
| トレンド強度 | MA20 > MA50 | +20 |
| 相対強度（RS） | RS > 5% | +20 |
| | RS 3〜5% | +10 |
| 出来高（RVOL） | RVOL ≥ 2.0倍 | +20 |
| | RVOL 1.5〜2.0倍 | +10 |
| | RVOL < 1.5倍 | ±0 |
| 終値強さ（body） | 終値が高値圏（≥80%） | +10 |
| セクター強度 | TOPIXより+2%超 | +20 |
| | TOPIXより+0〜2% | +10 |
| | TOPIXをアンダーパフォーム | ±0 |
| 市場環境 | BULLフェーズ以外 | −20 |

## 出口ルール（monitor.py）

判定は以下の優先順で行います（毎朝07:45・毎日16:20に実行）。

| 優先順 | ルール | 条件 |
|---|---|---|
| 1 | 全決済 | 市場フェーズ = CRASH |
| 2 | 決算またぎ回避 | 翌日が決算発表日 |
| 3 | 強制損切り | 損益 ≤ −5% |
| 4 | 建値保護 | +3%到達後に+0.5%割れ |
| 5 | ATR逆行ストップ | 終値 < エントリー − ATR14×1.5 |
| 6 | 資金流出検知 | 含み益あり かつ 終値位置 ≤ 20%（陰線引け） |
| 7 | MA25割れ | 終値 < MA25 |
| 8 | 保有期限 | 21日経過 |
